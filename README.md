# Florida Field Guide

Open the guide on any phone or computer:

https://philipgraffshapiro.github.io/florida-field-guide-site/

This repository contains the generated public edition: 721 destinations, 77 stays, maps, camping and work stops. Private notes and personal browser choices are excluded. Source version: e529f42.

The site is published by GitHub Pages from the root of main. Update only with a verified shareable build. Dates and prices in the guide are research snapshots; follow each place's sources for current information.
