# Florida Field Guide

Browse 882 Florida places, 877 map pins, and 329 lodging research records. The catalog was updated November 27, 2026. Individual photos, quotes, restrictions and campsite availability have their own source dates. [Open the Florida Field Guide](https://philipgraffshapiro.github.io/florida-field-guide-site/)

Campground details include official booking links, equipment, calendars, reviews and labeled photos where the publisher supplied them. The Stays filters use the selected town, dates and number of guests. The operator confirms current rates and availability.

The public map opens directly. A separate five-minute invitation requires an unused code issued by the sender. Its server enforces the redemption and viewing deadlines. Previously downloaded information can be retained.

The map loads first. The site retrieves detailed records, photos and optional panels as needed. `site-assets.json` records the byte length and SHA-256 of each generated asset. The map uses locally maintained Leaflet 1.9.4 and Leaflet.markercluster 1.5.3 components with their license notices.

GitHub Pages publishes the root of `main`. The checked source revision is `c0fb7889e835045867d8d8de1928f2a5e7098902`. Run `publish-site.mjs` in the source repository to verify and install a build. Keep earlier versioned assets available to cached pages.
